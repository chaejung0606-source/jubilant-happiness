# 회의록 자동 작성 도구

회의 자료가 들어있는 폴더를 넣으면, 폴더마다 회의록 1건을 사업단 표준 양식의
`.docx` 문서로 만들어 줍니다. API 키 없이 이 PC에 로그인된 Claude(Max 구독)로 동작합니다.

## 파일

| 파일 | 설명 |
|---|---|
| `회의록도구.pyw` | 본체 (GUI) |
| `회의록도구 실행.bat` | 실행기. 이 파일을 더블클릭하세요. |

두 파일은 **같은 폴더**에 두어야 합니다.

## 준비물

1. **Python** — <https://www.python.org/downloads/>
   설치 첫 화면에서 **"Add Python to PATH"** 를 반드시 체크하세요.
2. **Claude Code** — 명령 프롬프트에서 `claude --version` 이 동작해야 합니다.
   Claude 에 로그인까지 되어 있어야 합니다.

드래그&드롭용 `tkinterdnd2` 는 실행기가 처음 한 번 자동으로 설치합니다.
설치되지 않아도 버튼으로 폴더를 추가할 수 있습니다.

## 사용법

1. `회의록도구 실행.bat` 더블클릭
2. **＋ 회의 폴더 추가** 로 회의 1건의 자료 폴더를 넣거나,
   **＋ 상위 폴더 추가** 로 여러 회의 폴더가 든 상위 폴더를 한 번에 넣습니다.
   (드래그&드롭도 가능)
3. **출력 폴더 선택** 으로 저장 위치를 정합니다. (기본: 바탕화면 ＼ 회의록 생성)
4. **작업 시작** 을 누릅니다.
5. 완료된 줄을 더블클릭하면 만들어진 회의록이 열립니다.

`보완요청` 칸에 서류 간 날짜 불일치나 영수증 결제 시각 문제가 표시되며,
같은 내용이 회의록 문서 맨 위에도 적힙니다.

## 문제가 생겼을 때

**1) 창이 아예 뜨지 않는 경우**

명령 프롬프트에서 진단 모드로 실행하면 오류 메시지가 그대로 보입니다.

```
"회의록도구 실행.bat" debug
```

**2) 오류 기록 파일 확인**

`회의록도구.pyw` 와 같은 폴더의 `오류기록.txt` 에 실패 원인이 쌓입니다.
(폴더에 쓰기 권한이 없으면 임시 폴더에 기록됩니다.)

**3) "claude 명령을 찾을 수 없음"**

명령 프롬프트에서 `claude --version` 을 확인하세요. 동작하지 않으면 Claude Code 를
설치하고 컴퓨터를 다시 시작해야 합니다. npm 으로 설치한 `claude.cmd` 도 자동으로 찾습니다.

**4) `.bat` 을 직접 수정할 때 주의**

`회의록도구 실행.bat` 은 **CRLF 줄바꿈 + ANSI(CP949) 인코딩**으로 저장해야 합니다.
메모장에서 저장할 때 인코딩을 `ANSI` 로 지정하세요. UTF-8 이나 LF 줄바꿈으로 저장하면
윈도우 명령 프롬프트가 파일을 잘못 해석해 실행되지 않습니다.

## 문체·판단 기준 바꾸기

`회의록도구.pyw` 안의 `RULES` 문자열만 고치면 회의록 문체와 판단 기준이 바뀝니다.
양식 고정값(사업명 등)은 그 위의 `HEADER_TITLE`, `PROJECT_NAME`, `DEFAULT_ORG` 에 있습니다.
