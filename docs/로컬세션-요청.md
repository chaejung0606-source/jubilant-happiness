# 로컬 세션 요청문 (복붙용)

웹앱(이 리포)은 클라우드 세션이, 데스크톱 Excel·시트 쓰기는 로컬 세션이 맡는다.
아래 블록을 **통째로 복사해 로컬 세션에 붙여넣으면** 된다. 끝나면 결과 파일을 이 대화(클라우드)에 업로드.

> 갱신: 2026-10-23 · 담당 메뉴 = 자산(채번/이관)

---

## ▶ 지금 요청 (복붙 블록)

```
[COSS 자산관리 — 로컬 세션 작업 요청]

맥락: 이제 Excel이 아니라 웹앱(구글시트 DB)에서 자산을 관리한다.
      기존 대장 데이터와 채번 조회표를 웹앱으로 옮기려 한다.
      원본 대장은 수정하지 말고 '사본'에서만 작업하고, 결과는 CSV(UTF-8)로 내보내 줘.

대상 파일: C:\Users\User\Desktop\★사업단 운영\2. 자산 물품 관리\자산태그\자산관리대장(사본)
          (사본 예: 자산관리대장_261022.xlsm)

── 작업 1. 전체 대장 CSV 내보내기 (웹앱 이관용) ──
- 연번 1 ~ 915 전체 행을, 아래 17개 열 순서/머리글 그대로 CSV(UTF-8)로 저장.
- 관리번호는 O열 수식 결과값(문자열)을 넣는다. #N/A·빈 행은 제외.
- 열: 연번, 관리번호, 자산번호, RFID, 품명, 규격, 대분류, 중분류, 분류코드,
      취득일, 취득단가, 번호, 장소, 호실, 건축물코드, 관리기관, 사용처
  · 자산번호 = 학교 Z번호,  취득일 = YYYY-MM-DD,  취득단가 = 숫자만
- 파일명: 대장전체_YYYYMMDD.csv

── 작업 2. 건축물코드 표 전체 ──
- '건축물 코드' 시트의 (건물명 → B코드) 전체를 CSV로.
- 열: 건물명, 건축물코드
- 파일명: 건축물코드표.csv

── 작업 3. 중분류 → 분류코드 표 ──
- 품목 분류 조회표에서 (중분류명 → 분류코드) 전체를 CSV로.
  (가능하면 대분류도 같이)
- 열: 대분류, 중분류, 분류코드
- 파일명: 분류코드표.csv

완료 후 3개 CSV를 클라우드 세션 대화에 업로드. 추측 금지 — 애매하면 비워 두고 알려줘.
```
