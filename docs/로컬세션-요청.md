# 로컬 세션 요청문 (복붙용)

웹앱(이 리포)은 클라우드 세션이, 데스크톱 Excel·시트 쓰기는 로컬 세션이 맡는다.
아래 블록을 **통째로 복사해 로컬 세션에 붙여넣으면** 된다. 끝나면 결과 파일을 이 대화(클라우드)에 업로드.

> 갱신: 2026-10-23 · 담당 메뉴 = 자산(채번/이관)

---

## ▶ 지금 요청 (복붙 블록) — 전체 대장 이관 실행

```
[COSS 자산관리 — 웹앱 대장 이관 실행]

사전: 이 리포 최신화. 사이트 assets 시트는 현재 0행(새로 채움).

0. git pull                                  # apply:daesa 반입 모드 최신화
1. 미리보기:
   npm run apply:daesa -- "대장전체_20261023.csv"
   → "대상: 915건 (완성 대장 행)" 확인 (관리번호 그대로 사용, 재채번 없음)
2. 실제 반영:
   npm run apply:daesa -- "대장전체_20261023.csv" --commit
   # .env.local 의 SHEETS_API_URL/TOKEN 사용. 915건 append 라 수 분 소요.
3. 끝나면 사이트 /assets 에서 915건·관리번호 표시 확인.

※ 이전 dry-run 하던 'apply:daesa 기본 136건'은 실행하지 말 것(키가 달라 중복됨).
※ 재실행해도 관리번호가 키라 중복 추가 안 됨(이미 있으면 건너뜀).

(선택) RFID 교정 17건 — 연번 769~785:
  대장엔 전부 …00000036 으로 오기, 학교 쪽은 …040~056 로 각각 다름.
  학교 자산대장에서 이 17건의 올바른 RFID 를 (연번, RFID) 2열 CSV로 내보내 주면
  웹에서 --update 로 한 번에 교정함. 매칭이 불확실하면 그대로 두고 웹에서 건별 확인.
```

## (이전) 이관 자료 요청 — 완료

```
[COSS 자산관리 — 로컬 세션 작업 요청]

맥락: 이제 Excel이 아니라 웹앱(구글시트 DB)에서 자산을 관리한다.
      기존 대장 데이터와 채번 조회표를 웹앱으로 옮기려 한다.
      원본 대장은 수정하지 말고 '사본'에서만 작업하고, 결과는 CSV(UTF-8)로 내보내 줘.

대상 파일: C:\Users\User\Desktop\★사업단 운영\2. 자산 물품 관리\자산태그\자산관리대장(사본)
          (사본 예: 자산관리대장_261022.xlsm)

── 작업 1. 전체 대장 CSV 내보내기 (웹앱 이관용) ──
- 연번 1 ~ 915 전체 행을, 아래 17개 열 순서/머리글 그대로 CSV(UTF-8)로 저장.
- 관리번호는 O열 수식 결과값(문자열)을 넣는다. #N/A·빈 행은 제외.
- 열: 연번, 관리번호, 자산번호, RFID, 품명, 규격, 대분류, 중분류, 분류코드,
      취득일, 취득단가, 번호, 장소, 호실, 건축물코드, 관리기관, 사용처
  · 자산번호 = 학교 Z번호,  취득일 = YYYY-MM-DD,  취득단가 = 숫자만
- 파일명: 대장전체_YYYYMMDD.csv

── 작업 2. 건축물코드 표 전체 ──
- '건축물 코드' 시트의 (건물명 → B코드) 전체를 CSV로.
- 열: 건물명, 건축물코드
- 파일명: 건축물코드표.csv

── 작업 3. 중분류 → 분류코드 표 ──
- 품목 분류 조회표에서 (중분류명 → 분류코드) 전체를 CSV로.
  (가능하면 대분류도 같이)
- 열: 대분류, 중분류, 분류코드
- 파일명: 분류코드표.csv

완료 후 3개 CSV를 클라우드 세션 대화에 업로드. 추측 금지 — 애매하면 비워 두고 알려줘.
```
